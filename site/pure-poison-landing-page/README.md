# PURE POISON — Landing Page de Pré-venda

Landing page estática inspirada na linguagem visual de páginas cinematográficas de lançamentos:
hero em tela cheia, navegação discreta, grandes títulos serifados, seções imersivas,
transições de luz e CTA de captura.

## Como abrir

Abra `index.html` no navegador.

Para publicar, envie a pasta inteira para um serviço de hospedagem estática
ou servidor web.

## Captura de leads

O formulário está funcionando como demonstração: ele salva os e-mails no
`localStorage` do navegador.

Antes de usar em produção, substitua o trecho do `js/script.js` por uma chamada
ao seu backend, CRM ou serviço de formulários.

## Personalização

- Textos: `index.html`
- Cores, tipografia e layout: `css/style.css`
- Formulário e interações: `js/script.js`
- Imagens: `assets/images/`

As imagens usadas foram as fornecidas nesta conversa.
